# Assets Directory

This directory contains app assets. The placeholder files should be replaced with actual assets:

- **icon.png**: App icon (1024x1024px, PNG format)
- **splash.png**: Splash screen image (2048x2048px, PNG format)  
- **adaptive-icon.png**: Android adaptive icon foreground (1024x1024px, PNG format)
- **favicon.png**: Web favicon (192x192px or 48x48px, PNG format)

## Quick Setup

You can use Expo's asset generator or create your own:

```bash
# Using Expo CLI
npx expo-asset-generator --help

# Or use online tools like:
# - https://www.appicon.co/
# - https://www.makeappicon.com/
# - Figma/Sketch design tools
```
